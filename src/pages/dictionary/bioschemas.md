Bioschemas supports structured descriptions of life-science resources using schema.org. [ARC RO-Crate](/details/arc-ro-crate/) profiles map the ARC Abstract Model's concepts into publication metadata using schema.org and Bioschemas terms.

Find out more about Bioschemas on the [official website](https://bioschemas.org/).
