The ARC community develops tools for annotation, collaboration, validation and publication. A Domain ARC combines these tools with community metadata standards, workspace conventions and publication profiles. This catalog primarily covers [ISA ARC](/details/isa-arc/), the reference domain implementation developed with DataPLANT.

Within ISA ARC, [ARCitISA](/details/tools-and-services/ARCitISA/) supports workspace management and annotation, [ARCtrl](/details/tools-and-services/ARCtrl/) provides programmatic access and transformations, and [PLANTdataHUB](/details/tools-and-services/PLANTdataHUB/) supports collaboration and continuous validation. [ARChigator](/details/tools-and-services/ARChigator/) and [ARChive](/details/tools-and-services/ARChive/) connect reviewed submissions to publication.

The catalog also includes specialized community tools and earlier applications. Supported formats and profiles depend on the tool and version. The [ARC RDM system overview](/details/arc-representation/) explains how these working environments connect to the Publication Space through shared model structures and defined transformations.
