**Enabling access to MIAPPE-compliant ISA-based datasets through BrAPI.** MIRA supports deployment of a Breeding API (BrAPI) server for an ISA-based ARC workspace containing phenotyping information compliant with the Minimal Information About a Plant Phenotyping Experiment (MIAPPE) standard. It uses the supported workspace structure and metadata to populate the endpoints. These are conventions of that implementation, rather than requirements of every ARC workspace.
