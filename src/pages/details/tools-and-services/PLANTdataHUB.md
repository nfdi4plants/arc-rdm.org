An established implementation of the [ARC Data Hub concept]({{INTERNAL_DEV_ARC_DATA_HUB}}), providing **collaborative Git-based workspaces for [ISA ARC](/details/isa-arc/)** through GitLab. It includes self-hosting and federation options.
Continuous Quality Control (CQC) pipelines run selected validation packages distributed through [AVPR](/details/tools-and-services/avpr/). The results provide feedback as the workspace evolves. Passing publication checks enables a researcher to inspect and submit a publication request through [ARChigator](/details/tools-and-services/ARChigator/); review and publication in [ARChive](/details/tools-and-services/ARChive/) follow separately.

The [ARC Search](/details/tools-and-services/ARCSearch/) service can be used to search for ARCs across federated instances. See [validation](/details/validation/) and the [publication workflow](/details/exchange-and-publication/) for the scope of automated checks and subsequent review.
