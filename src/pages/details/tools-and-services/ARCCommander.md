A command-line tool for creating, managing and sharing [ISA ARC Workspaces](/details/arc-workspace/isa-arc/).

ARCCommander sets up the [ISA ARC directory structure](/details/organization-principle/#isa-arc-directory-structure), initializes version control and provides commands to manipulate supported metadata. These conventions belong to ISA ARC; the wider [ARC RDM architecture](/details/arc-representation/) accommodates other workspace organizations.

Its commands can be used in shell scripts to work with multiple workspaces.
