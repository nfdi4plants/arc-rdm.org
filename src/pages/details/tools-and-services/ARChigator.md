**The submission interface connecting [PLANTdataHUB](/details/tools-and-services/PLANTdataHUB/) to [ARChive](/details/tools-and-services/ARChive/).** After the selected publication checks pass, the DataHUB publication badge opens ARChigator.

Researchers inspect the proposed files and metadata before submitting a request for publication. ARChigator tracks the request through review and any required revisions. Passing automated validation enables submission; publication still requires acceptance by the reviewers.

See the [publication workflow](/details/exchange-and-publication/) for the roles of validation, review and DOI publication.
