A .NET, Python and JavaScript library for working with [ISA ARC Workspace](/details/arc-workspace/isa-arc/) structures and metadata.
ARCtrl provides parsing, writing and manipulation operations, including transformations into supported [ARC representations]({{INTERNAL_DEV_REPRESENTATION}}). It models investigations, studies, assays, workflows, runs and their annotation tables. Format, API and profile support depend on the library version.
You can read more about the ARCtrl developer toolkit [here]({{INTERNAL_DEV_TOOLSTACK}}).
