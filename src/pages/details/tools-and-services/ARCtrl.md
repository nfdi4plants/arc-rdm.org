A .NET, Python and JavaScript library for working with [ISA ARC Workspace](/details/arc-workspace/isa-arc/) structures and metadata.
ARCtrl provides parsing, writing and manipulation operations, including transformations into supported [ARC RO-Crate](/details/arc-ro-crate/) representations. It models investigations, studies, assays, workflows, runs and their annotation tables. Format, API and profile support depend on the library version.

The [ISA ARC overview](/details/isa-arc/) places the library within the domain implementation. Read the [developer toolkit guide]({{INTERNAL_DEV_TOOLSTACK}}) for its APIs and representation layers.
