At RPTU University Kaiserslautern-Landau, the Regional University Computing Center (RHRZ) provides **[RPTU DataHUB](https://datahub.rz.rptu.de)** for collaborative management of research data and metadata. The GitLab-based service organizes research in ARC projects and supports version control, including Git Large File Storage for larger files. Researchers can manage project visibility and invite collaborators while keeping data and their descriptions together.

An integrated registry automatically records ARC metadata, allowing researchers to find relevant projects through metadata terms. Institutional accounts from the Rhineland-Palatinate computing-centre alliance (RARP) can be used to request project groups, and external collaborators can join existing groups. Researchers can work through ARC tools or the DataHUB web interface, supporting shared research documentation as projects develop.

Read the [RPTU DataHUB service description](https://rz.rptu.de/en/forschung/fdm/datahub) for access information and current capabilities.
